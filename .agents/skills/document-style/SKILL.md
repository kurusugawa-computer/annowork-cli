# 全般
* 異なるコマンドで、同じオプションについての詳細な説明が必要な場合は、同じ内容を繰り返すのではなく、リンクを利用してできるだけ共通化してください。メンテナンスコストを下げるためです。

* ファイルを出力するコマンドでは、対応する形式の出力結果の例を必ず示してください。CSVとJSONの両方に対応するコマンドでは、両方の形式で出力例を示してください。単一形式のみ対応する場合は、その形式の出力例を示し、対応形式を明記してください。
    * CSV形式での出力例では、`:file:`オプションを使用して、出力ファイルを指定してください。

* 破壊的変更した際、その内容をドキュメントに残さないでください。いずれ陳腐化するためです。
