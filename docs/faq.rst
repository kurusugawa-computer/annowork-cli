==========================================
FAQ
==========================================

annoworkcliコマンドが見つからない
==========================================

インストールした仮想環境を有効化し、次のコマンドで確認してください。

.. code-block:: bash

    python -m pip show annoworkcli
    python -m annoworkcli --version

パッケージが見つからなければ、そのPython環境にインストールしてください。
手順は :doc:`user_guide/getting_started` を参照してください。

認証情報の入力を求められて処理が進まない
==========================================

実行するプロセスに認証情報が設定されているか確認してください。
Annoworkでは ``ANNOWORK_USER_ID`` と ``ANNOWORK_PASSWORD`` の両方が必要です。
``--annowork_user_id`` のみを指定した場合は、環境変数の有無にかかわらずパスワードの対話入力になります。
設定の優先順位とAnnofabの認証情報は :doc:`user_guide/configurations` を参照してください。

ワークスペースIDが必要というエラーになる
==========================================

``--workspace_id`` または環境変数 ``ANNOWORK_WORKSPACE_ID`` を指定してください。
``annoworkcli my list_workspace_member --format json`` で、自分が所属するワークスペースのIDを確認できます。
詳しくは :doc:`user_guide/command_line_options` を参照してください。

認証エラーやアクセス権限のエラーになる
==========================================

まず ``annoworkcli my get`` で、自分のアカウント情報を取得できるか確認してください。
失敗する場合は :doc:`user_guide/configurations` の設定を確認してください。
成功して対象ワークスペースの操作で失敗する場合は、ワークスペースIDと操作権限を確認してください。
Annofab APIにアクセスする場合は、Annofab側の認証情報と対象プロジェクトのアクセス権限も確認してください。

JSONを指定したつもりなのにCSVが出力される
==========================================

``--output jobs.json`` は出力先を指定するだけです。
``--format json`` を持つコマンドでは、このオプションも指定してください。
詳しくは :doc:`user_guide/cli_usage_output` を参照してください。

取得結果が空になる
==========================================

ワークスペースID、ジョブID、ユーザーID、日付の絞り込み条件を確認してください。
日付を集計する場合はタイムゾーンも確認してください。
``actual_working_time list_daily`` では、実績作業時間が0の行は出力されません。
コマンドごとの絞り込み条件は :doc:`command_reference/index` を参照してください。

エラーの詳細を調べたい
==========================================

実行したコマンドに ``--debug`` を付けてログを確認してください。
ログの場所と出力先の分け方は :doc:`user_guide/cli_usage_output` を参照してください。
ログにはHTTPリクエストの内容が含まれるため、共有する前に内容を確認してください。
