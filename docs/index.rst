annowork-cli
==================================================

ドキュメントの読み方
==================================================

annoworkcliはAnnoworkのCLIです。ジョブやメンバーの管理、作業時間の取得・集計、Annofab連携を行えます。

初めて利用する場合は :doc:`user_guide/getting_started` から、インストール・認証・初回実行を確認してください。
AIや自動実行に利用する場合は、User Guideの認証設定・入力・出力の説明と、実行するコマンドのリファレンスを読み込んでください。
