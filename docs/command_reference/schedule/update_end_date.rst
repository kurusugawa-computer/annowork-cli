==================================================
schedule update_end_date
==================================================

Description
=================================
1つの親ジョブの作業計画について、条件に一致する全計画の終了日を指定日にそろえます。
延長・短縮の両方に対応し、開始日・担当者・アサイン先・割当時間／割合は維持します。
アサイン先IDの意味は :doc:`index` を参照してください。

対象の選択
=================================
現在の終了日が昨日以前の計画は、必ず除外します。
「今日」は実行開始時に、実行環境のローカル日付で一度だけ決定します。
今日以降に終了する計画には、将来開始する計画も含まれます。

以下の絞り込み条件をすべてANDで適用します。

* ``--parent_job_id``: アサイン先の親ジョブIDを1個指定します。必須です。
* ``--user_id``: 対象ユーザーを限定します。複数指定または ``file://`` による一覧ファイルを指定できます。省略時は全員が対象です。
* ``--from_end_date``: 現在の終了日の下限です。指定日を含みます。
* ``--to_end_date``: 現在の終了日の上限です。指定日を含みます。

終了日の範囲を省略すると、今日以降に終了する全計画が対象です。
最も遅い終了日の計画だけを選んだり、ユーザーごとに1件だけを選んだりすることはありません。
同じユーザーに複数の計画がある場合も、条件に一致する全計画を対象にします。
対象が0件の場合は警告と集計結果を表示し、正常終了します。

入力検証・更新時の動作
=================================
``--end_date`` は変更後の終了日で、必須です。当日を含みます。
``--end_date``、``--from_end_date``、``--to_end_date`` はすべて ``YYYY-MM-DD`` 形式で、今日以降の日付を指定してください。
過去日・不正な形式・下限が上限を超える範囲は、APIアクセス前にエラーにします。
変更後の終了日が対象計画の開始日より前になる場合は、全件の更新前にエラーにします。
開始日と終了日が同じ場合は、1日間の計画として有効です。

更新前に、対象のユーザー・作業計画ID・開始日・変更前後の終了日をinfoログで表示し、まとめて1回確認します。
``--dry_run`` では、確認や書き込みをせず、変更予定を表示します。対象計画はスキップとして集計します。
現在と同じ終了日を指定した計画もスキップします。

確認の省略、ID一覧ファイル、成功・スキップ・失敗件数の表示、APIエラー時の継続・非0終了は :doc:`create` と同じです。
競合検出と、存在しない計画を作成しない動作は :doc:`update` と同じです。
更新には一覧取得時の更新日時を送信し、取得後に変更された計画を上書きしません。
失敗した計画IDと変更前の終了日をwarningログに残します。
成功済みの更新を取り消すことはありません。

Examples
=================================
以下の例は、実行日が2026-10-10の場合です。

今日以降に終了する全員の計画を11/30終了にそろえます。

.. code-block:: bash

    annoworkcli schedule update_end_date --workspace_id org \
      --parent_job_id parent1 --end_date 2026-11-30

10/15〜10/31に終了する計画だけを延長します。10/1に終了済みの計画は変更しません。

.. code-block:: bash

    annoworkcli schedule update_end_date --workspace_id org \
      --parent_job_id parent1 --from_end_date 2026-10-15 \
      --to_end_date 2026-10-31 --end_date 2026-11-30

aliceとbobの、現在の終了日が11/30の計画だけを11/15に短縮します。
まず ``--dry_run`` で確認し、実際に更新する際にはこのオプションを外します。

.. code-block:: bash

    annoworkcli schedule update_end_date --workspace_id org \
      --parent_job_id parent1 --user_id alice bob \
      --from_end_date 2026-11-30 --to_end_date 2026-11-30 \
      --end_date 2026-11-15 --dry_run
