==================================================
schedule update_start_date
==================================================

Description
=================================
1つの親ジョブの作業計画について、条件に一致する全計画の開始日を指定日にそろえます。
前倒し・延期の両方に対応し、終了日・担当者・アサイン先・割当時間／割合は維持します。
アサイン先IDの意味は :doc:`index` を参照してください。

対象の選択
=================================
現在の開始日が昨日以前の計画は、終了日が将来でも必ず除外します。
「今日」は実行開始時に、実行環境のローカル日付で一度だけ決定します。
このコマンドは、今日以降に開始する計画の開始日を変更するためのものです。

以下の絞り込み条件をすべてANDで適用します。

* ``--parent_job_id``: アサイン先の親ジョブIDを1個指定します。必須です。
* ``--user_id``: 対象ユーザーを限定します。複数指定または ``file://`` による一覧ファイルを指定できます。省略時は全員が対象です。
* ``--from_start_date``: 現在の開始日の下限です。指定日を含みます。
* ``--to_start_date``: 現在の開始日の上限です。指定日を含みます。

開始日の範囲を省略すると、今日以降に開始する全計画が対象です。
ユーザーごとに1件だけを選ぶことはありません。
同じユーザーに複数の計画がある場合も、条件に一致する全計画を対象にします。
対象が0件の場合は警告と集計結果を表示し、正常終了します。

入力検証・更新時の動作
=================================
``--start_date`` は変更後の開始日で、必須です。当日を含みます。
``--start_date``、``--from_start_date``、``--to_start_date`` はすべて ``YYYY-MM-DD`` 形式で、今日以降の日付を指定してください。
過去日・不正な形式・下限が上限を超える範囲は、APIアクセス前にエラーにします。
変更後の開始日が対象計画の終了日より後になる場合は、全件の更新前にエラーにします。
開始日と終了日が同じ場合は、1日間の計画として有効です。
終了日を自動的に延期することはありません。

更新前に、対象のユーザー・作業計画ID・終了日・変更前後の開始日をinfoログで表示し、まとめて1回確認します。
``--dry_run`` では、確認や書き込みをせず、変更予定を表示します。対象計画はスキップとして集計します。
現在と同じ開始日を指定した計画もスキップします。

確認の省略、ID一覧ファイル、成功・スキップ・失敗件数の表示、APIエラー時の継続・非0終了は :doc:`create` と同じです。
競合検出と、存在しない計画を作成しない動作は :doc:`update` と同じです。
更新には一覧取得時の更新日時を送信し、取得後に変更された計画を上書きしません。
失敗した計画IDと変更前の開始日をwarningログに残します。
成功済みの更新を取り消すことはありません。

Examples
=================================
以下の例は、実行日が2026-11-01で、対象計画の終了日が12/15以降の場合です。

今日以降に開始する全員の計画を12/15開始にそろえます。

.. code-block:: bash

    annoworkcli schedule update_start_date --workspace_id org \
      --parent_job_id parent1 --start_date 2026-12-15

12/1開始の計画だけを12/15に延期します。

.. code-block:: bash

    annoworkcli schedule update_start_date --workspace_id org \
      --parent_job_id parent1 --from_start_date 2026-12-01 \
      --to_start_date 2026-12-01 --start_date 2026-12-15

aliceとbobの、現在の開始日が12/15の計画だけを12/1に前倒しします。
まず ``--dry_run`` で確認し、実際に更新する際にはこのオプションを外します。

.. code-block:: bash

    annoworkcli schedule update_start_date --workspace_id org \
      --parent_job_id parent1 --user_id alice bob \
      --from_start_date 2026-12-15 --to_start_date 2026-12-15 \
      --start_date 2026-12-01 --dry_run
